# V01 — User-requested rendering clarity correction

22 September 2026. The user reported textures moving with the player and asked
for higher resolution because the presentation looked too old. This correction
takes priority over the original PS1 affine/snapping rule and precedes M12.

- Perspective-correct UV interpolation is now the default. Local box projection
  remains object-bound; imported props retain their authored UVs.
- Vertex snapping is disabled by default. Both legacy effects remain opt-in
  diagnostic switches, and snapping uses actual viewport dimensions if enabled.
- Internal rendering increases from 320×240 to 640×480; default window 1280×960,
  verified 2× nearest enlargement. Interface fonts/margins scale proportionally.
- Dither strength 0.35, chromatic separation 0.05, grain 0.004. Asset paths and
  source PNGs remain unchanged; PSX-first asset selection continues.

Live MCP validation:

- Actual framebuffer 640×480, window 1280×960. Audit finds zero world meshes with
  affine_mapping or vertex_snap enabled.
- [Passage before movement](V01/passage.png) and [after translation/turn](V01/moved.png)
  show stable perspective texture mapping. Camera moves from (0,0.02,4.8) to
  (0.32,0.02,4.1), yaw +0.06 radians. No affine surface stretching is applied.
- [Main menu](V01/menu.png) and [station panel](V01/panel.png) retain readable
  proportions. An actual mouse click through the 2× transform turns panel power
  off; panel reports 640×480. All captured frames are fresh.

17 GUT tests / 82 assertions pass in 25.308 seconds. Windows export succeeds;
headless exported probe advances 66 process/30 physics frames, real D3D12 probe
advances 24 process/30 physics frames. Both exit successfully without GPU errors.

This supersedes M06–M08 defaults; their evidence remains historical. The existing
64px surface textures still give a deliberately low-detail art style; this change
removes camera-dependent distortion and increases image/UI clarity.
