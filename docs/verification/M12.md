# M12 — Versioned save/load and Continue

Version 1 persists operator pose, elapsed time, local panel/light power and settled
airlock state. Pause includes Save Game; return-to-menu and Quit/window-close save
before discarding the world. Save failure preserves the running world.

Live MCP restart check used the isolated slot `user://tests/live_m12/save.json`:

1. Move to (4.3,0.001,1.4), yaw 0.72, pitch -0.21; elapsed time 123s.
2. Turn off the command light and primary CRT, then [save](M12/saved.png).
3. Stop and restart the game process; [Continue becomes available](M12/continue.png).
4. Click Continue through the actual 2×-scaled interface. Position/yaw/pitch
   restore within float precision, elapsed time is 123.003353s after resuming,
   and the light and CRT remain off. [Restored visual state](M12/restored.png).

22 GUT tests / 120 assertions pass in 26.761s, covering actual state round trips,
missing/corrupt saves, checksum mismatch, invalid data, interrupted staging and
rotation, backup recovery, unsupported-version preservation, and mid-cycle save
rejection. Loaded airlock transforms are applied immediately, including while
paused. Unsupported versions never silently fall back to an older backup.

The initial tests exposed noisy JSON parse failures and physics-synchronized door
restore delay. Both were corrected before acceptance. Float pose assertions use
appropriate tolerances rather than requiring identical JSON/native precision.
Queued old worlds are allowed to finish disposal in test cleanup; no orphan warning
remains. Live editor log is clear.

Windows export passes; its headless probe advances 65 process/30 physics frames.
Details and extension rules: [Persistence](../PERSISTENCE.md). Later systems add
their state and migration coverage as they are implemented.
