# M08 — PS1 compositor effects

Implemented as a real `CompositorEffect` at POST_TRANSPARENT on Forward Plus,
using a precompiled compute shader. Live GPU pipeline reports valid; both
diagnostic and integrated bunker runs have no editor/runtime rendering errors.

The source frame is copied into a viewport-owned scratch buffer before any
neighbour reads. Pass order is chromatic separation, perceptual 5-bit/channel
Bayer dithering, then fine grain. The image is returned to linear space for
Godot's remaining output pipeline. No source textures are altered.

Same camera and fixed phase 42, separately enabled effects:

| Comparison against disabled baseline | Changed scene pixels |
| --- | --- |
| Dither | 69,120 |
| Chromatic aberration | 14,602 |
| Grain | 58,201 |

- [Integrated bunker](M08/bunker.png): fresh 320×240 frame; corridor edges,
  warm/cool lighting and signs remain distinguishable. Default strengths are
  dither 1, chroma 0.18, grain 0.012; grain changes at 15Hz independently of physics.

Compositor attachment is by WorldEnvironment type, not node name. A diagnostic
initially passed while the bunker's differently named environment was missed;
this was corrected and the actual bunker re-run before acceptance.

10 GUT tests / 53 assertions pass in 20.461 seconds. Headless tests deliberately
skip GPU allocation; visual checks above establish rendered behavior. An initial
Variant inference parse error was fixed before the passing run.
