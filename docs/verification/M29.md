## Verification incident

An earlier live check changed `GameSession.save_path` after initialization, but the existing SaveService retained its original path. That check wrote its fixture into the default slot twice, rotating away the prior backup. The earlier user slot could not be recovered. The resulting main/backup files were copied to ignored `builds/verification/default_save_after_m29_test.json` and `.bak`; this is preservation of the resulting fixture, not recovery of the prior slot. The user was notified immediately after discovery.

The property now rebuilds the SaveService when its path changes. A dedicated regression verifies that runtime path switching writes the alternate file while leaving the original byte-identical. Subsequent live verification uses explicit isolated paths.

Tuning and organic-horror readability remain human playtest questions; this is not a claim of fun or campaign pacing.
