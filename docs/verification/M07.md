# M07 — PS1 surface materials

Live MCP diagnostic uses the verified PSX source
`Textures/PSX modular house interior pack/geometry/floorStone_albedo.png`.
Only its import sidecar changes: 64px maximum, mipmaps disabled. Live texture
inspection confirms 64×64 and no mipmaps; the shader uses nearest sampling.
No fallback texture is used.

- [Snapping + affine enabled](M07/on.png), [affine disabled](M07/off.png).
  Same stationary camera and geometry; 28,420 scene pixels differ. The oblique
  plane visibly changes from perspective convergence to triangle-linear warping.
- [Camera turned 0.006 radians](M07/turn.png), [same pose without snapping](M07/unsnapped.png).
  10,691 scene pixels differ, including quantized outer edges and their UVs.
- [Near-plane case](M07/near.png): camera 2cm above the plane, 5cm near clip,
  with geometry crossing behind the eye. Clipping remains bounded; no GPU errors.
- [Integrated bunker](M07/bunker.png): all 42 MeshInstance3D nodes use the PS1
  shader, with zero invalid materials reported by the running game.

The shader rounds clip-space XY onto the 320×240 grid, preserving depth/W.
It interpolates UV×W and W, then divides them to cancel reciprocal-W weighting.
Diagnostic switches default on and are never disabled in production materials.
World labels remain font-rendered UI, separate from surface texture policy.

Fresh frames captured throughout. Editor error log is empty. Full GUT suite:
10 tests / 53 assertions passed in 20.433 seconds. Test completion was recovered
from the saved log after the shell session expired during a user interruption.
