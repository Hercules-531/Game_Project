earned pads and off-spine marquee nests. No existing opening camera or recovery
objective moves. Original surface landmarks remain in place; these checkpoints

- Supplies are physical PSX box props through the existing recover/carry/unload
  pipeline, never proximity credits or replenishing loot. Scrap quantity and
  bulk increase northward; fuel/rations support finite campaigns. Larger
  northern loads reward earned carrying hardware rather than bypassing it.
- Native stone/metal shelter forms use verified PSX surface textures. No
  additional bitmap, sound library, creature type or parked GDD feature enters

- Nest integrity rises by 100 per band, and independent growth clocks shorten
  northward using the already-established escalation model. Content rank must
  agree with these actual mechanics, not merely a map label.
- Save the number of authored bands present when a run was written. Older
  saves preserve every collected/carried/delivered crate and receive only newly
  authored sites as available. Reload never reissues an old reward.
